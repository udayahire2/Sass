# NMU Study Hub Documentation

This folder documents the current product and backend implementation for mentor review.

Recommended reading order:

1. `01-introduction.md` - Product purpose, modules, and high-level user journey.
2. `02-user-types.md` - Student, faculty, and admin roles.
3. `03-requirements.md` - Functional and non-functional requirements.
4. `04-system-architecture.md` - Frontend, backend, routes, data flow, and deployment notes.
5. `05-database-design.md` - SQLite tables, relationships, indexes, and soft deletes.
6. `06-api-endpoints.md` - REST API reference.
7. `07-authentication.md` - OTP, JWT, refresh tokens, and authorization.
8. `08-file-storage.md` - Upload handling, file paths, limits, and production notes.

Short summary:

NMU Study Hub is a React + Express + SQLite academic resource platform. It supports student/faculty signup, OTP verification, admin faculty approval, study-material uploads, content moderation, syllabus management, resource management, and admin dashboards.
